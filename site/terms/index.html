Hotkey Runbook is a local utility for running commands you or your organization author. You are responsible for reviewing runbooks, parameter values, required permissions, and rollback procedures before execution.

The source code is available under the MIT License. A valid existing license adds unlimited runbooks and extended local history for one user across their devices. Core safety, accessibility, and the useful free tier remain available without a license.

Existing licenses

New license sales are unavailable until checkout is registered. You may restore a valid existing license token. A revoked license no longer verifies.

Execution boundaries

On Linux systems that permit Landlock, child file changes are limited to the reviewed working folder and child privilege gains are disabled. File reads and network access are not isolated. macOS and Windows currently have no process sandbox. The consent screen states the active boundary before each run.

The product does not provide remote orchestration or a secret vault. It runs local processes with your current operating-system permissions. Review unfamiliar YAML outside the app before signing its folder.
